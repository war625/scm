# 상품 등록 요구사항 (루프의 "목표")
- R1 상품명이 비어 있으면 등록되지 않는다.
- R2 판매가가 0 이하이면 등록되지 않는다.
- R3 이미 등록된 상품명(공백·대소문자 무시)은 다시 등록할 수 없고, 상품명 필드에 '이미' 가 포함된 오류 메시지를 보여준다.
- R4 할인율은 0~90 범위로 보정된다(95→90, 음수→빈 값). 보정된 값이 미리보기 최종가와 저장 데이터에 반영된다.
- R5 이미 올린 이미지(파일명+크기 동일)를 다시 올리면 추가되지 않고 '이미' 가 포함된 오류 토스트를 보여준다. 파일명이 다르면 정상 추가된다.

규칙: 이 파일과 tests/verify.cjs 는 루프 중 수정 금지. 수정 대상은 js/, product.html 뿐.
